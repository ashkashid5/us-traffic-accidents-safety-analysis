# U.S. Traffic Accidents & Safety Analysis (Final Project)

This project analyzes U.S. traffic accident patterns using a cleaned dataset to identify trends and risk factors. The analysis is implemented in a Jupyter Notebook and produces insights via data cleaning and visual exploration.

## What’s inside
- `Final.ipynb` — notebook with the full analysis workflow
- `data/cleaned_accident_data.csv` — cleaned dataset used by the notebook
- `report/Final Project Report.pdf` — final written report

## Tech stack
- Python (Jupyter Notebook)
- pandas, numpy, requests, matplotlib

## How to run (recommended)
1) Create and activate a virtual environment  
   **Windows**
   - `py -m venv .venv`
   - `.venv\Scripts\activate`

   **macOS/Linux**
   - `python3 -m venv .venv`
   - `source .venv/bin/activate`

2) Install dependencies  
   - `pip install -r requirements.txt`

3) Run the notebook  
   - Open `Final.ipynb`
   - Run cells top-to-bottom
